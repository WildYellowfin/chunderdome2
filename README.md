# Chunderdome II

A small Next.js app for planning the Chunderdome II camping trip to Dillon Beach (Nov 13–15, 2026): phone sign-in, onboarding, a personal packing list, and an admin dashboard for cars, gear, food, and money.

## What it does

**For everyone**
- Sign in with a phone number (SMS code via Twilio Verify, or a shared trip code).
- Six-step onboarding: name, and (only if they tick it) which part of the weekend they can make; how they're getting there (ride with the group, drive and take people, or make their own way), with a pickup pin on a drag-to-place map centred on Clay House (1473 Clay St) for anyone in the cars, car size and trunk space for drivers, and when they need to be home Sunday; sleeping bag and pad, gear to lend (bags, pads, tents with sizes), essential and useful gear they're bringing, dietary needs, optional Venmo, and the $35 food budget (free for drivers) plus an optional $20 booze kitty.
- Drivers log fuel and tolls under Me after the trip; transport is split evenly across everyone in the cars, drivers included. People making their own way pay no transport.
- Trip home page: illustrated map, countdown, itinerary, meal plan, their car and carmates, and the crew.
- A packing list built from their answers that they tick off as they go.

**For admins** (`/admin`)
- Signups vs the 22 RSVPs, cars and seats vs people riding with the group, riders without a car.
- Car cards with seat maps, and a dropdown to assign each rider to a car.
- A pickups map with every pin (drivers with seat counts), plus people and seats by neighbourhood.
- Sunday return times, including who needs to be back early.
- Gear: sleeping bags and pads needed vs lent, tent beds vs people, headlamps and chairs vs headcount, and who's bringing what.
- Dietary roll-up, and a money table with food, booze, transport share, and each person's total (drivers can come out owed).
- Copy every phone number for a group text, download everything as CSV.
- Add or remove admins. Owners (from `OWNER_PHONES`) can't be removed.

Trip details (times, meals, Clay House, neighbourhoods, gear lists) live in `lib/trip.ts`. The pickup maps use MapLibre with OpenFreeMap vector tiles (free, no key), styled in the poster palette in `lib/mapStyle.ts`.

## Deploy to Vercel

1. Import this repo in Vercel.
2. In the project's **Storage** tab, add **Upstash for Redis** (free tier is plenty). It sets `KV_REST_API_URL` and `KV_REST_API_TOKEN` for you.
3. Add environment variables:
   - `SESSION_SECRET`: a long random string (`openssl rand -base64 32`).
   - `OWNER_PHONES`: your number, e.g. `+14155550123` (comma-separate for more).
   - Sign-in, pick one:
     - `TRIP_CODE`: a passcode you post in the group chat. Simple and free.
     - `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_VERIFY_SERVICE_SID`: real SMS codes.
   - With neither set, anyone can sign in as any number, so set one of them.
4. Deploy.

## Local development

```bash
npm install
cp .env.example .env.local   # set OWNER_PHONES to your number
npm run dev
```

Without Redis env vars the app stores data in `.data/db.json`.

## The map

The hero is `public/route-map.svg` (PNG fallback `public/route-map.png`), a 4:5 screen-print poster map made with Monge's picture tools (image generation guided by real coordinates, traced to vector and recoloured to the app palette), with the route, markers and type drawn as native SVG on top. How it was made, with every command, is in `map/poster/notes.md`; sources and scripts are alongside.

The older landscape map, still in the repo:

`public/map.svg` is generated by `map/build-map.ts`. It authors each layer (coastline, hills, forests, the bridge, the route, the Chunderdome) as SVG from real coordinates and composes them with the [Monge](https://github.com/WildYellowfin/monge) kernel. To rebuild after editing:

```bash
MONGE_DIR=../monge bun map/build-map.ts
```
