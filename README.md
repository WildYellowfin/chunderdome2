# Chunderdome II

A small Next.js app for planning the Chunderdome II camping trip to Dillon Beach (Nov 13–15, 2026): phone sign-in, onboarding, a personal packing list, and an admin dashboard for cars, gear, food, and money.

## What it does

**For everyone**
- Sign in with a phone number (SMS code via Twilio Verify, or a shared trip code).
- Six-step onboarding: name and rough area, emergency contact, how they're getting there, car and seats, where they'll sleep, sleeping bag and pad, spare gear to share, dietary needs, Venmo, and agreeing to the $30 food budget (+ optional $20 booze kitty).
- Trip home page: illustrated map, countdown, itinerary, meal plan, their car and carmates, and the crew.
- A packing list built from their answers that they tick off as they go.

**For admins** (`/admin`)
- Signups vs the 22 RSVPs, cars and seats vs people riding with the group, riders without a car.
- Car cards with seat maps, and a dropdown to assign each rider to a car.
- Who's where: people, drivers, and seats by area.
- Gear sufficiency: sleeping bags and pads needed vs spares offered, Chunderdome space (16) vs people who want in, and every spare item with who has it.
- Dietary roll-up, Venmo list with what each person owes, missing Venmos and emergency contacts.
- Copy every phone number for a group text, download everything as CSV.
- Add or remove admins. Owners (from `OWNER_PHONES`) can't be removed.

Trip details (times, meals, areas, gear lists) live in `lib/trip.ts`.

## Deploy to Vercel

1. Import this repo in Vercel.
2. In the project's **Storage** tab, add **Upstash for Redis** (free tier is plenty). It sets `KV_REST_API_URL` and `KV_REST_API_TOKEN` for you.
3. Add environment variables:
   - `SESSION_SECRET`: a long random string (`openssl rand -base64 32`).
   - `OWNER_PHONES`: your number, e.g. `+14155550123` (comma-separate for more).
   - Sign-in, pick one:
     - `TRIP_CODE`: a passcode you post in the group chat. Simple and free.
     - `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_VERIFY_SERVICE_SID`: real SMS codes.
   - With neither set, anyone can sign in as any number, so set one of them.
4. Deploy.

## Local development

```bash
npm install
cp .env.example .env.local   # set OWNER_PHONES to your number
npm run dev
```

Without Redis env vars the app stores data in `.data/db.json`.

## The map

`public/map.svg` is generated by `map/build-map.ts`. It authors each layer (coastline, hills, forests, the bridge, the route, the Chunderdome) as SVG from real coordinates and composes them with the [Monge](https://github.com/WildYellowfin/monge) kernel. To rebuild after editing:

```bash
MONGE_DIR=../monge bun map/build-map.ts
```
